# Simulacion_banco
Diseño de un modelo de simulación del sistema de atención de clientes en una agencia bancaria
Este trabajo desarrolla un modelo de simulación de eventos discretos (Python + SimPy) del proceso de atención en ventanilla de una agencia bancaria, con el fin de analizar el comportamiento del sistema actual (2 cajeros) e identificar oportunidades de mejora frente a los tiempos de espera y la congestión que se generan en horas de mayor demanda.

Se recolectaron datos reales en campo (100 observaciones de clientes) para estimar el tiempo entre llegadas y el tiempo de atención, y con esa información se construyó el modelo computacional, se validó contra los datos observados, y se evaluaron distintos escenarios de capacidad (1, 2, 3 y 4 cajeros) para proponer una alternativa de mejora al proceso.

El informe sigue la estructura típica de un estudio de simulación: planteamiento del problema, modelo conceptual, análisis estadístico de los datos, ajuste de distribuciones, modelo computacional, validación, resultados del escenario base y análisis de escenarios alternativos.
